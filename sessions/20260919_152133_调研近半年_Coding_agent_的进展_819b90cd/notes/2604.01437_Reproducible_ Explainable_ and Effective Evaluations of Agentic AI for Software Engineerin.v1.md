# Reproducible, Explainable, and Effective Evaluations of Agentic AI for Software Engineering

读取范围：full_text

问题：无

- 结果显示，使用基于 LLM 的摘要来分析 TAR 轨迹以规模化产出可解释的智能体行为定性评估是可行的。（页码：4）
  > The results illustrate the feasibility of using LLM-based summarization to analyze TAR trajectories to produce interpretable, qualitative evaluations of agent behavior at scale.

- 跨模型分析中，时间与上下文验证被识别为最强的成功模式；Llama-3.3-70B通过先检查基础事实（日期、版本、CVE元数据）再深入代码分析而持续优于其他模型。（页码：6）
  > **Temporal and contextual verification** emerges as the strongest success pattern. Llama-3.3-70B consistently outperforms others by checking foundational facts first-dates, versions, CVE metadata-before diving into code analysis.

- 决定性因素是分析纪律而非推理复杂性；Llama的70B参数通过更严格遵循验证协议（检查日期、版本、受影响文件和工具输出）胜过Qwen的235B，而非通过更深的推理链。（页码：6）
  > The decisive factor is **analytical discipline over reasoning sophistication**. Llama's 70B parameters outperform Qwen's 235B not through deeper reasoning chains, but through stricter adherence to verification protocols: check dates, check versions, check affected files, check tool outputs.
