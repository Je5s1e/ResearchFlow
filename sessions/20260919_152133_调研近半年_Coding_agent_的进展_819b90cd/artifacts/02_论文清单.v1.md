# 论文清单



- 入选：[A Mixed-Method Empirical Study of LLM Assistance in Software Engineering Workflows](https://arxiv.org/abs/2609.04214) — 入选：混合方法实证研究 LLM 辅助软件工程工作流，覆盖实现、约束算法选择、架构推理等任务，分析 AI 辅助 vs 非 AI 的工作流差异与验证实践，与 Coding Agent 在 SE 任务中的人机协作和任务依赖性直接相关；国内属性需进一步核验，但主题契合度高。

- 排除：[Aleena: Alignment Agent for Research Software Engineering Collaborations](https://arxiv.org/abs/2607.08043) — 排除：研究软件工程协作中的对齐 agent，侧重多模态利益相关者交互与项目状态跟踪，非代码智能体的系统架构、训练或 SWE 基准表现；国内属性不明显。

- 入选：[Reproducible, Explainable, and Effective Evaluations of Agentic AI for Software Engineering](https://arxiv.org/abs/2604.01437) — 入选：聚焦 Agentic AI 在软件工程中的可复现、可解释与有效评估，分析 ICSE/FSE/ASE/ISSTA 论文并提出 TAR 轨迹公开等指南，与 Coding Agent 评测方法、复现性问题直接相关；作者含 Jingyue Li，可能为国内关联学者，优先保留。

- 排除：[Prompt Engineering Strategies for LLM-based Qualitative Coding of Psychological Safety in Software Engineering Communities: A Controlled Empirical Study](https://arxiv.org/abs/2605.07422) — 排除：研究 LLM 辅助定性编码的提示工程，面向软件工程社区心理安全分析，与 Coding Agent 代码生成/修复/评测无直接关系。

- 排除：[The Semi-Executable Stack: Agentic Software Engineering and the Expanding Scope of SE](https://arxiv.org/abs/2604.15468) — 排除：概念性 keynote，提出 Semi-Executable Stack 诊断模型，未涉及具体 Coding Agent 系统架构、训练范式或国内仓库级实践；作者团队非国内机构，与本次调研核心相关性弱。

- 排除：[An Empirical Evaluation of Locally Deployed LLMs for Bug Detection in Python Code](https://arxiv.org/abs/2604.23361) — 排除：评估本地部署 LLM 的 Python bug 检测，属于 LLM 辅助缺陷定位，非 Coding Agent 系统架构/训练范式，也未体现国内机构或中文开发场景，相关性有限。

- 入选：[SWE-Bench Pro Verified: A Reliable Benchmark for Software Engineering Agents](https://arxiv.org/abs/2609.08149) — 入选：针对 SWE-Bench Pro 的奖励黑客与任务质量问题提出验证版基准，直接关联 Coding Agent 的 SWE 类基准评测与真实能力评估，作者团队疑似国内机构，是本次国内 Coding Agent 评测方向的核心候选。

- 排除：[The Open Ant: A Robot Platform for Reinforcement Learning Research](https://arxiv.org/abs/2607.18488) — 排除：强化学习机器人平台，与 Coding Agent 主题完全无关。

- 排除：[Multi-Agent Reinforcement Learning from Delayed Marketplace Feedback for Objective-Weight Adaptation in Three-Sided Dispatch](https://arxiv.org/abs/2606.13604) — 排除：三边市场派送的强化学习系统，属于运营优化，与 Coding Agent 主题无关。

- 排除：[Towards Reliable, Generalizable, and Specific In-Context Knowledge Editing via Multi-Objective Reinforcement Learning](https://arxiv.org/abs/2608.25100) — 排除：上下文知识编辑的多目标强化学习，与 Coding Agent 主题无关。

- 排除：[Closing the Feedback Loop: From Experience Extraction to Insight Governance in Verbal Reinforcement Learning](https://arxiv.org/abs/2606.17591) — 排除：语言强化学习中的经验抽取与洞察治理，以金融预测为例，与 Coding Agent 无关。
